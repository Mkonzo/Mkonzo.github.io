# PrepWise – Smart Study Planner

PrepWise is a smart study planner that helps students organise their studies and stay on track. It is a simple website built with HTML, so it is easy to open, understand and customise.

🔗 **Live demo:** [PASTE YOUR FULL LINK HERE](https://mkonzo.github.io/)

---

## ✨ Features

- **Study planning:** organise what you need to study and when.
- **Easy to use:** a clean, simple interface that is friendly for beginners.
- **Works in any browser:** no installation or sign-up needed.
- **Responsive design:** works on phones, tablets and computers.

### Option 1: Visit the live site

Open the live demo link above in your browser.

1. Clone the project:

   ```bash

   ```

2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

## 🌐 Deployment

This site is hosted with **GitHub Pages**:

1. Push your code to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Source**, choose the `main` branch and save.
4. Your site will be live at `https://mkonzo.github.io/YOUR-REPO-NAME/`.
